# Host generator runtime libraries

Ubuntu 22.04 amd64 libc++abi1-14 and libunwind-14, version 1:14.0.0-1ubuntu1.1. Required by the pinned openvela AIDL generator. SHA256 values are in ../../tools/build-support/host-packages.json.

Original packages: https://archive.ubuntu.com/ubuntu/pool/universe/l/llvm-toolchain-14/ and https://archive.ubuntu.com/ubuntu/pool/main/l/llvm-toolchain-14/ . Packages retain their embedded copyright and license files under usr/share/doc. They are extracted locally, never installed system-wide.
