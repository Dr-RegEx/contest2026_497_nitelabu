# Korvo 标准按键检查命令

`s31keys [秒数]` 通过 `/dev/buttons` 的标准 `read/poll/BTNIOC_*` 接口检查四个功能键，默认30秒，允许1–300秒。到时或出错后关闭设备并返回；不使用守护任务或全局“已启动”标志，可再次执行。

位值：PLAY=1、SET=2、VOL-=4、VOL+=8，0表示松开。支持键集合必须为0x0f，否则明确报错。驱动负责采样、去抖、迟滞和ADC资源管理，应用不直接访问ADC。

主工程 `korvo-camera-touch-sd-keys` 资格配置启用本命令及原始值日志。后续获得板测操作条件后，可运行 `s31keys 30`，依次记录松开和四键的raw分布，修订阈值后再验证实际事件。`s31keys 10 &` 和 `s31keys 15 &` 可验证多客户端退出。此配置尚未完成实板校准，也未证明与摄像/触摸/SD并发稳定；RF、温度和SMP组合仍待共享ADC电源适配。独立双核视觉Demo不受本命令影响。

工作区 `tools/tests/korvo-adc-keys` 包含实际驱动、NuttX按钮上半部与本应用的主机故障测试、Kconfig检查及交叉构建入口。主机测试不替代按钮实物测试。
