# ESP32-S31 SoC 驱动

ESP32-S31 芯片级启动、双核、内存、中断和外设适配实现。

板级引脚与外设组合见 boards/risc-v/esp32s31/esp32s31-core-function-board；应用入口在 apps/examples 的 s31 系列。修改本目录后需选择相应配置构建并进行相关实板回归。
