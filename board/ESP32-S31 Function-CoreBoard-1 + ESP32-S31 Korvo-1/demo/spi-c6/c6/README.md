# SPI-C6 配套 C6 工程

本目录保留历史 fixture 源码和验证脚本，来源为 `workspace/tools/esp32c6-spi-slave`。S31 应用来源、许可和 canonical 配置见 [例程说明](../README.md)。历史结果与边界见 [验证索引](../../../../../docs/validation/README.md)，旧结果不作为新固件验收。

历史连线 S31→C6：45→4（SCLK）、46→5（MOSI）、47→6（MISO）、48→7（CS）、GND→GND。断电接线，分别 USB 供电，不互连 5V/3V3。C6 工程使用 ESP-IDF `14f663f003eb8fd9a688c301a412a9540d29dacf`；在已准备好该版本环境的终端进入本目录，以 `idf.py build` 构建。设备操作时按实际板卡选择端口，S31 镜像使用其 canonical profile 及对应镜像布局。

## 协议与验收

Mode 0、MSB first、每字节8位、每帧16字节。C6 第一帧返回 A0..AF，之后每帧返回上一次收到的16字节。主机两帧之间留出至少100ms，供 C6 打印日志并重新挂起接收。先测100kHz，再测1MHz，发送不同模式并比对上一帧原文，同时核对 C6 接收日志。

示例 S31 命令：

```text
spi exch -f100000 -x16 000102030405060708090a0b0c0d0e0f
spi exch -f100000 -x16 55555555555555555555555555555555
```

第二条应收到 `00 01 ... 0F`。接收到全零或仅命令成功不能判通过。
