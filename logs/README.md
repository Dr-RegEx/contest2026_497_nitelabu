# AI coding logs

This directory contains 184 recovered Codex sessions and 1647 original user/assistant events, from 2026-09-03 through 2026-11-04.

Files use `logs/<github-login>/<date>/codex__<session-id>.jsonl`, with a member `manifest.json`. `export-provenance.json` records the official parser revision and per-file hashes.

Privacy filtering withdraws entire sessions. Retained JSONL files are copied unchanged from canonical exports; conversation text, timestamps and sequence numbers are not edited. Raw recovered history is retained privately. This selected set does not represent every development conversation.

The pinned official validator passes. The previous rewritten excerpt and example session have been withdrawn rather than merged into this set.

See the [official AI coding log guide](https://github.com/open-vela/docs/blob/dev-ai-contest-2026/zh-cn/contest_2026/ai_coding_log_guide.md) for the submission format and whole-session privacy policy.
